# 01. Запуск и обзор

## Запуск

- Исполняемый файл: `CtpuBintapeTimechannel` (ребрендинг OpenHantek6022;
  заголовок окна пока показывает строку версии вида
  `OpenHantek6022 (0.0.x-N-g<hash>)` — хвост ребрендинга).
- **Демо-режим:** ключ `--demoMode` (или `-d`) — приложение работает без
  прибора на синтетическом сигнале. Все органы управления живые; в
  заголовке — «Demo Mode». Используется для проверки GUI и обучения,
  не для измерений.
- С прибором: ISDS205B определяется по VID/PID, прошивка fx2lafw
  загружается автоматически. [СБОРКА]

## Панели (доки)

- **Voltage** — каналы CH1/CH2/MATH: глава [02](02-voltage.md).
- **Horizontal** — развёртка, формат отображения, панель XY-рекордера,
  выход калибратора: глава [03](03-horizontal.md).
- **Trigger** — режим (Auto/Normal/Single/Roll), источник, фронт. Триггер
  у ISDS205 **только программный** (стандартный термин: *software
  trigger*, запрос по уже захваченным данным, а не аппаратный гейт
  захвата) — события между кадрами могут теряться, это свойство прибора.
- **Spectrum** — включение спектра по каналам (БПФ; *FFT*).

Панели перетаскиваются и скрываются через меню **View**; раскладка
сохраняется между сеансами.

## Возраст кадра в HUD [СБОРКА]

Рядом со статусом триггера отображается **возраст кадра** «N ms»
(стандартный термин: *Age of Information, AoI*) — время от преобразования
сырых данных до вывода на экран. Правило проекта (D-05): измерение
достоверно только вместе со своей давностью.

Ожидаемое поведение: единицы миллисекунд в норме; рост числа под нагрузкой
означает, что отрисовка отстаёт, но данные не копятся — стык GUI работает
как «почтовый ящик с вытеснением» (*overwrite mailbox*, единственный слот,
новый кадр замещает непоказанный старый; в рекордеры при этом попадает
**каждый** кадр, вытеснение касается только отображения). Латентность
не нарастает по построению.

## Сохранение настроек [СБОРКА]

Все органы, описанные в этом мануале, пишут значение в настройки в момент
изменения (*write-through*) и восстанавливаются при следующем запуске.
