# 03. Панель развёртки (Horizontal)

Всё в этой главе — **[СБОРКА]**.

## Базовые органы

- **Timebase** — время на деление (*s/div*), шаги 1-2-5.
- **Samplerate** — эффективная скорость выборки (Sps; не путать с частотой
  сигнала в Hz), выбирается автоматически из Timebase, можно задать явно.
  Пониженные скорости получаются передискретизацией (*oversampling*) с
  усреднением — это повышает SNR.
- **Format** — T-Y (сигнал во времени) или **XY**.
- **Continuous recording** (чекбокс, активен только в формате XY; прежнее
  имя «XY Recorder» вводило в заблуждение и заменено) — непрерывная запись
  сразу в две структуры:
  - **поле XY** — настоящая XY-запись: плоскость делится на ячейки по
    значениям ОБЕИХ осей (**XY field bins, X / Y** — два независимых
    числа, 2..8192), копится плотность посещений; форма сигнала
    (меандр, ВАХ, петля) сохраняется;
  - **лента** (BinTape/CIC) — усреднение по времени записи: полезно для
    медленных сигналов, форма из неё невосстановима.
  Включение блокирует конфигурационные поля до выключения.
- **Calibration out** — частота встроенного калибратора (меандр 2 В):
  100 Гц / 1 / 10 / 25 кГц у ISDS205B.

## Панель XY-рекордера

Видна только в формате XY. Правило У1: на панели нет мёртвых полей —
каждое поле видно, только если выбранная модель его действительно читает.

### Выбор модели децимации

- **BinTape (streaming bins)** — основная модель: лента из фиксированного
  числа бинов; при переполнении соседние бины сливаются попарно, ничего
  не отбрасывается. Поля:
  - **Bins on tape** — длина ленты в бинах (500..50000, фиксированный ряд:
    число должно нацело делиться пополам при слияниях). Единственный
    параметр количества точек в модели.
  - **Median prefilter** — медианный префильтр (*median filter*, порядковая
    статистика) перед биннингом: Off или окно 3..15. Убирает коммутационные
    иглы и звон, чтобы min/max бина отражали реальный размах сигнала.
    Потолок 15 — измерено на тестовых данных: окна ≥31 срезают пики
    сигнала, при этом «доля энергии остатка» остаётся у нуля — контроль
    по **пику остатка**, не по энергии (правило C9).
- **CIC cascade (legacy)** — прежняя каскадная модель (среднее boxcar перед
  каждой ступенью децимации; литература CIC), оставлена для сравнения.
  Её поля: Master axis, Expected X/Y slew rate, Track sigma, Extraction
  (Cascade mean / Peak envelope), Target points (лист) или Target density
  (лента).

### Общие поля обеих моделей

- **Time axis** — чувствительность оси времени для XY-кривых, где одной из
  осей выбрано Time (глава [04](04-xy-recorder.md)): защёлки 1-2-5 от
  нс/дел до ч/дел. Единственное поле, **не** блокируемое во время записи:
  это чувствительность отрисовки, менять безопасно.
- **Sheet mode** — «Finite sheet» (фиксированное число точек) или «Tape»
  (фиксированная плотность, поток на диск).
