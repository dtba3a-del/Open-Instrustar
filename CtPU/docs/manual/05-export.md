# 05. Экспорт

Всё в этой главе — **[СБОРКА]**.

## Меню Export

- **Export CSV ..** — захваченные данные каналов в CSV; метка времени
  захвата в шапке (ISO 8601 с миллисекундами).
- **Export JSON ..** — то же в JSON. Структура: верхнеуровневое поле
  `"captured"` — момент экспорта, ISO 8601 с миллисекундами (У7; формат
  сознательно не локализован — сортируем и однозначен), затем массив
  `"channels"` с CtPU-метаданными каждого канала (`mode`, `unit`, `k`,
  `b` — позволяют восстановить физические единицы на стороне обработки),
  затем данные.
- **Export XY Data ..** — текущая траектория XY-рекордера в CSV, по файлу
  на кривую; столбца времени нет (для кривых с осью Time время — это
  столбец соответствующей оси). Выбирается каталог, имена файлов —
  по кривым.
- Скриншот/печать — штатные функции OpenHantek, без изменений.

## Замечание о точности времени

`"captured"` — часы ПК (оценка; см. intra/epoch в главе
[04](04-xy-recorder.md)). Для сопоставления записей двух приборов класса
«миллисекунды» этого достаточно; точнее — только методом общего
источника (общий калибратор на оба входа, взаимная корреляция; реестр
D-07).
