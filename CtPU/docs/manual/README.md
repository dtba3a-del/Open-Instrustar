# Руководство оператора — правила и оглавление

Справка приложения CtPU/BinTape/TimeChannel (форк OpenHantek6022 под
Windows 11 x64 / MSYS2 MinGW64 / Qt5 / InstruStar ISDS205B, путь B —
fx2lafw + libusb).

Автор проекта, архитектуры и знака — **dtba3a** (`dtba3a@gmail.com`).
Руководство, как и остальные материалы проекта, принадлежит ему.

## Правила ведения мануала (распоряжение автора проекта)

1. **Пишется сразу.** Разобрал или сделал подсистему — в тот же заход глава
   здесь. Откладывание = повторный разбор кода по памяти, с неточностями.
2. **Метка состояния на каждом нетривиальном утверждении:**
   - *без метки* — проверено на приборе;
   - **[СБОРКА]** — подтверждено только сборкой и автотестами, на железе
     не проверялось;
   - **[ПЛАН]** — кода нет, описано намерение.
   Утверждение без метки, не проверенное железом, — ошибка документации,
   равная ошибке в коде.
3. **Термины** — по [`../GLOSSARY.md`](../GLOSSARY.md): термин проекта и
   термин стандарта рядом, при первом употреблении в главе.
4. **Числа с условиями.** Полоса, частоты, окна — всегда с указанием, откуда
   число (даташит/расчёт/измерение) и при каких условиях.
5. Мануал описывает **это** приложение (путь B). Факты вендорского стека
   (путь A, vdso.dll) сюда не переносятся — см. `../ACCESS_PATHS.md`.
