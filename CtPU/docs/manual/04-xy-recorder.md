# 04. XY-рекордер и ось Time

Всё в этой главе — **[СБОРКА]**.

## Идея

Формат XY рисует один канал против другого (фигуры Лиссажу, ВАХ,
петли гистерезиса). XY-**рекордер** превращает это в самописец:
траектория **накапливается** на ленте BinTape непрерывно, кадр за кадром,
а не перерисовывается каждым кадром заново.

В рекордеры попадает **каждый** захваченный кадр независимо от того,
успевает ли экран (см. «возраст кадра», глава [01](01-start.md)):
вытеснение на стыке GUI касается только отображения.

## Кривые

До **4 кривых** на общей сетке. Настройка: **Config → CtPU → вкладка XY**:
для каждой кривой — Enabled, **X channel**, **Y channel** (списки по
именам каналов) и строка Preview с текущими осями и ценой деления.

Смена пары осей у кривой **очищает её ленту** (лента привязана к паре
осей); смена любых других параметров ленту сохраняет. Счётчик точек
кривой — честный индикатор накопления: если он стоит, накопления нет,
какой бы правильной ни выглядела фигура (урок A-07).

## Ось Time: T-Y как частный случай XY (У3)

В списке осей X/Y есть пункт **Time**: время — полноправный канал
(философия TimeChannel), и классическая развёртка T-Y — это просто
XY-кривая, у которой X = Time.

- Чувствительность оси — поле **Time axis** панели Horizontal
  (защёлки 1-2-5, нс/дел..ч/дел; в легенде — «T», единица «s»).
- Отрисовка — рулоном (*roll mode*): новейшая точка у правого края,
  история уезжает влево.
- Два источника времени, честно разделены:
  - **внутрикадровое** (intra): индекс отсчёта / samplerate — измерено;
  - **межкадровое** (epoch): метка часов ПК на момент преобразования
    кадра — оценка; USB-джиттер порядка миллисекунд. Для абсолютных
    временных измерений между кадрами это предел точности пути B.
- Медианный префильтр к оси времени не применяется (остаток времени
  тождественно нулевой); пара Time×Time не строится.

## Легенда

В углу XY-экрана — легенда кривых: имена осей и цена деления по каждой
(для Time — из поля Time axis). Единицы осей следуют CtPU-настройке
канала (В или физическая единица).

## Поле против ленты (важно)

Лента бинирует **позицию в порядке записи** и хранит по бину среднее —
это усреднение за большое время, а не XY-запись: у меандра оба уровня
падают в один отрезок ленты, и среднее садится между ними (дефект найден
пользователем на приборе, 2026-08-21). Поле бинирует **значения обеих
осей** — это и есть XY-запись (плотность посещений, тот же принцип, что
у цифрового фосфора): форма сигнала сохраняется. Разрешение поля — два
независимых числа ячеек по осям.

## Экспорт

Меню **Export XY Data ..** пишет **два файла** на каждую включённую
кривую (CSV, UTF-8):

- `xy_field_curveN_*` — поле: `ix,iy,x_center,y_center,count,
  t_first_ms,t_last_ms`, только посещённые ячейки; в шапке — сетка,
  диапазоны, clippedX/Y (отсчёты ЗА пределами сетки — не путать с
  границей);
- `xy_tape_average_curveN_*` — лента: средние по отрезкам записи, с
  явным предупреждением в шапке, что форма из этого файла
  невосстановима.

Прочий экспорт — глава [05](05-export.md).
