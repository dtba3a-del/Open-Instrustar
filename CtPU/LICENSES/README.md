# LICENSES — полные тексты лицензий

Здесь лежат полные тексты всех лицензий, под которыми распространяются
компоненты проекта. Соответствие «компонент → лицензия → правообладатель»
описано в [docs/THIRD_PARTY.md](../docs/THIRD_PARTY.md).

| Файл | Идентификатор SPDX | Под ней распространяются |
|---|---|---|
| `GPL-3.0-only.txt` | `GPL-3.0-only` | Сам проект, OpenHantek6022, Hantek6022API, libsigrok, Zadig |
| `GPL-2.0-or-later.txt` | `GPL-2.0-or-later` | FFTW, sigrok-firmware-fx2lafw |
| `LGPL-2.1-or-later.txt` | `LGPL-2.1-or-later` | libusb |
| `LGPL-3.0-only.txt` | `LGPL-3.0-only` | Qt 5, libwdi |
| `MIT.txt` | `MIT` | UsbGpib |

`GPL-3.0-only.txt` совпадает с корневым [LICENSE](../LICENSE) — лицензией
самого проекта. Дубль сделан намеренно: корневой файл отвечает на вопрос «под
чем распространяется этот проект», а каталог `LICENSES/` — «какие вообще
лицензии здесь действуют».

## Откуда взяты тексты

Файлы, кроме `GPL-3.0-only.txt`, — эталонные тексты из реестра
[SPDX License List](https://github.com/spdx/license-list-data). Тексты с
gnu.org получить не удалось: домен закрыт политикой сетевого доступа среды, в
которой формировался репозиторий.

**Если компонент поставляет собственную копию лицензии — приоритет у неё.**
Так, `cmake/fftw-3.3.5-dll64.zip` содержит свой `COPYING`; он отличается от
эталонного текста SPDX ненормативным приложением «How to Apply These Terms to
Your New Programs» и редакционной правкой FSF (`Library` → `Lesser`
в заключительном абзаце). Тело лицензии в обоих случаях одно и то же — GNU GPL
версии 2.

`MIT.txt` — шаблон с заполнителями `<year>` и `<copyright holders>`.
Конкретные правообладатели указаны в
[docs/THIRD_PARTY.md](../docs/THIRD_PARTY.md), а действующий экземпляр
поставляется вместе с самим компонентом.

## Как добавлять

Появляется компонент под лицензией, которой здесь ещё нет — кладите её
эталонный текст сюда файлом `<SPDX-идентификатор>.txt` **в том же коммите**,
что и сам компонент, и добавляйте строку в таблицу выше и запись в
`docs/THIRD_PARTY.md`.
