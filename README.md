## CtPU — осциллографическое приложение для ISDS205B

Каталог [`CtPU/`](CtPU/) — приложение CtPU: осциллограф, XY-регистратор и
генератор DDS для InstruStar ISDS205B. Цель сборки одна: **Windows 11 x64,
MSYS2 MinGW64, Qt5**. Других платформ и приборов у него нет.

Собранные архивы — на вкладке **Releases**. Сборка запускается вручную:
Actions → «CtPU Build» → Run workflow.

**Лицензия — GPL-3.0** ([`CtPU/LICENSE`](CtPU/LICENSE)). Приложение
происходит от [OpenHantek6022](https://github.com/OpenHantek/OpenHantek6022),
и его лицензия унаследована. Соответствующий исходный текст к каждому
двоичному выпуску (GPL-3.0 §6) — это сам каталог `CtPU/` в том коммите, с
которого выпуск собран.

Лицензии остальных компонентов кладутся в каждый архив, каталог `licenses/`;
их тексты берутся у самих пакетов сборочной среды, а состав с версиями —
в `licenses/СОСТАВ.txt`.

Комментарии в исходниках ссылаются на документы вида `docs/…`,
`references/…`, `sessions/…`. Это документы **основного репозитория проекта**,
который приватен; здесь их нет. Ссылка означает «разбор записан там», а не
отсутствующий файл.

### О `CtPU/vendor/vdso.dll`

Это библиотека InstruStar (仪星电子 / YiXingDianZi), x86-64, 184 320 Б, 73
экспорта. Она **не** та же, что `Dll-windows/VDSO.dll` выше: та — 32-битная,
54 экспорта, прошлое поколение SDK, и 64-битное приложение её не загрузит.

**Лицензии у неё не существует** — ни в SDK, ни в репозитории вендора
<https://github.com/instrustar-dev/SDK/>, куда отсылает README выше. Файл
включён решением автора проекта, потому что без него окно генератора DDS не
работает вовсе. Правами на этот файл проект не обладает и никому их не
передаёт. Автору библиотеки направлено письмо с просьбой определить лицензию
на материалы, выложенные в её репозитории.
